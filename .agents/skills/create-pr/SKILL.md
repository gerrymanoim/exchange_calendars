# Create a Pull Request

On creating any pull request, or on updating the body of one, do the following:
- **PR body**:
    - avoid minutiae.
    - lay the body out as the `pr-body-layout` skill defines.
    - do not use the PR template (@.github/pull_request_template.md). The template is for PRs that do not employ an agent.
